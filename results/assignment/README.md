## 1. What Run 0 is (one paragraph)

Run 0 applies the pretrained model to our test images with no fine-tuning. It is the baseline for the two fine-tuning runs: Run A (original noise schedule θₜ) and Run B (modified schedule θₜ^x, x = 2.00). Run 0 is **done**: 30 EUVP test pairs, 155 minutes on a T4. Runs A and B are not started.

## 2. The result in three lines

- Output vs reference: **17.72 dB PSNR, 0.732 SSIM** (mean over 30 images).
- The saved input vs the same reference: 19.85 dB, 0.779. So the pretrained model does **not** beat "do nothing" on average (9 of 30 images improve on PSNR).
- Likely reasons: EUVP "reference" images are enhanced images in their own style (not ground truth), and the checkpoint was trained on a different dataset. This makes Run 0 a low baseline that fine-tuning should beat.

Full numbers and caveats are in `Run0_Report.md`.

### Things the notebook does not make obvious

- **The dataset name in the log is wrong on purpose.** Step 7 prints `Dataset [UIEDataset - UIEB]`. That label comes from the authors' config. The data actually used is `/content/euvp_test`, which you can see in the `dataroot` line of the printed config. Do not cite that log line as the dataset.
- **Output files are named `0_<k>_<kind>.png`.** `0` is the step number (always 0 in inference), `k` is the image index starting at 1 in sorted-filename order, and `kind` is `input`, `output`, `target` or `denoising_process`.
- **"input" is not the raw image.** The repo applies colour channel compensation to the input in its data loader, and `test.py` saves that compensated version. Step 8 shows both (raw and compensated).
- **`denoising_process.png`** is a grid: the first panel is the compensated input, then 10 reverse-diffusion frames at t = 1809, 1608, ..., 201, 0. The last panel is the final output.
- **Sampling takes about 5.2 min per image** because it runs all 2000 steps. 30 images is about 2.6 hours. Do not set `N_IMAGES` high without checking this.
- **The seed is set once at the start**, in a wrapper (`/content/run0_test.py`), because the repo's `test.py` has no seed and we did not edit it.

## 4. How to interpret the numbers

- **PSNR** is in dB, higher is better. **SSIM** is 0 to 1, higher is better. Both compare an image with the EUVP reference, which is an enhanced image and not true ground truth.
- Compare **output vs reference** with **input vs reference**. If the output does not beat the input, the model has not moved the image closer to the reference.
- Per-image PSNR varies a lot (std about 2.8 dB across images). Treat differences smaller than about 1.5 dB between two runs on 30 images as inconclusive. The standard error of the mean paired difference is about 0.8 dB.
- The metrics here are from scikit-image (`data_range=255`, `channel_axis=2`) on 256 × 256 images. The repo's own `eval.py` compares the input with the target, so ignore it.

## 6. The metrics cell we actually used (not in the notebook file)

The Colab runtime disconnected after Step 7 finished, so Step 8 did not run in that session. The numbers in the report were computed straight from the files on Drive with this standalone cell. It does not need a GPU.

```python
from google.colab import drive
drive.mount('/content/drive')
import glob, os, numpy as np, pandas as pd
from PIL import Image
from skimage.metrics import peak_signal_noise_ratio as psnr, structural_similarity as ssim

exp = "/content/drive/MyDrive/FoundationModel-Assignment/run0_diffwater_live/Run0_EUVP_261028_194635"
idxs = sorted({int(os.path.basename(p).split("_")[1]) for p in glob.glob(f"{exp}/0_*_output.png")})
need = ["input", "output", "target", "denoising_process"]
complete = [i for i in idxs if all(os.path.exists(f"{exp}/0_{i}_{k}.png") for k in need)]
print("images with all 4 files:", len(complete), "of 30; missing:", sorted(set(range(1, 31)) - set(complete)))

load = lambda i, k: np.array(Image.open(f"{exp}/0_{i}_{k}.png").convert("RGB"))
rows = []
for i in complete:
    out, tgt, inp = load(i, "output"), load(i, "target"), load(i, "input")
    rows.append(dict(idx=i,
        psnr_out=psnr(tgt, out, data_range=255), ssim_out=ssim(tgt, out, channel_axis=2, data_range=255),
        psnr_in=psnr(tgt, inp, data_range=255),  ssim_in=ssim(tgt, inp, channel_axis=2, data_range=255)))
df = pd.DataFrame(rows)
df.to_csv("/content/drive/MyDrive/FoundationModel-Assignment/run0_metrics_from_drive.csv", index=False)
print(df.round(3).to_string(index=False))
print(df[["psnr_out", "ssim_out", "psnr_in", "ssim_in"]].agg(["mean", "std"]).round(3))
```

Column meaning: `psnr_in` and `ssim_in` use the **colour-compensated** input that `test.py` saved. Notebook Step 8 reports `psnr_raw` and `ssim_raw` against the resized raw image instead. Those two are different quantities, so do not mix them in one table.
